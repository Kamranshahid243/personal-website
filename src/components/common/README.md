# `components/common`

Composite components shared across sections and pages, built _from_ the shadcn
primitives in `components/ui` rather than replacing them: `theme-toggle.tsx`,
`project-card.tsx`, `post-card.tsx`, `social-links.tsx`, `availability-badge.tsx`,
`copy-email-button.tsx`.

The line against `components/ui` matters: `ui` is vendored, regenerated by the
shadcn CLI, and knows nothing about this site. Anything here is ours and is
free to import from `@/config`, `@/data` and `@/lib`. Keeping that boundary
clean is what makes `shadcn add --overwrite` a safe command to run.
